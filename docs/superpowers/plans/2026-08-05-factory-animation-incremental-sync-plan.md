# Factory Animation Incremental Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a server-managed official factory animation catalog that syncs new, replaced, and deleted official animations to the ESP32-S3 firmware and Flutter app without app rebuilds or manual SD-card copying.

**Architecture:** The Node server owns the catalog, immutable revisioned downloads, ZIP staging, and admin UI. The encoder emits device `.eb4` files, app previews, and import ZIPs. ESP32-S3 and Flutter each fetch the catalog once per boot/start, verify hashes, and apply transactional local updates; F022/F023 are official loop animations using direct loop playback.

**Tech Stack:** Node.js built-in `node:test`, Flutter/Dart, ESP-IDF C, Python encoder, FFmpeg.

## Global Constraints

- Server is the source of truth for official factory animations.
- App checks once at startup and may download over mobile data.
- ESP32-S3 checks once after STA has stable IP; it must not continuously poll.
- F001-F021 are protected baseline animations: replace allowed, delete rejected.
- Server-managed non-baseline items may be added, replaced, and deleted.
- F022 and F023 are `loop` official animations, not `split` or `transition`.
- Existing F006/F007 special directional transitions must remain unchanged.
- Clients verify SHA-256 and size before publishing files.
- Malformed, empty, or older catalogs must not remove protected baseline files.
- The server never generates `.eb4`; it imports files generated by the local encoder.

```python
def normalize_factory_loop_id(stem: str) -> str:
    name = stem.upper()
    if name.startswith("F"):
        name = name[1:]
    number = int(name)
    return f"F{number:03d}"

def discover_factory_loop_sources(src_dir: Path) -> list[tuple[str, Path]]:
    loop_dir = src_dir / "factory_loop"
    if not loop_dir.exists():
        return []
    return [
        (normalize_factory_loop_id(path.stem), path)
        for path in sorted(loop_dir.glob("*.mp4"), key=natural_key)
    ]
```
